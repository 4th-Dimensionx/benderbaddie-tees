# BenderBaddie

A luxury streetwear storefront concept for custom graphic tees, cross-vendor fits, and limited drops.

## Stack
- Next.js 14
- TypeScript
- App Router
- Custom CSS

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Main pages
- Home storefront
- Custom order form
- API routes for catalog and custom request handling
